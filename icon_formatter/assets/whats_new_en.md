# What is new

- Studio: import images, folders, icon packs or the phone's apps and turn them all into the same style.
- Adjustments for each icon, background removal, and plate shape and colour for each icon.
- Undo and redo changes, select several icons, search, sort and filter them.
- Style presets you can share or import from a file, with an accent colour for the Glass style.
- Pack: matches new icons to your installed apps, lets you check every match and builds the icon pack.
- Quality check and conflicts before you build the pack, with aliases and variants for other apps.
- Dynamic calendar: the calendar icon always shows today's date. Home-screen preview to check the result.
- Background like the pack: the background transparency matches the other icons.
- On Android you install and apply it directly, or export it and install it by hand.
- Automatic update: when you install a new app, the pack updates itself.
- Your apps: process the icons of installed apps and send them to the pack.
- Share with Icon Formatter and watched folder: images arrive in the Studio.
- Automatic backup and update check, which you can turn off in Settings.
- Welcome tour, which you can replay from Settings.
- Two styles, Nothing and Glass, in light or dark mode. Languages: Italian, English, Spanish, French, German and Portuguese.
